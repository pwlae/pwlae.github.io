Prefix sums

Read first: Arrays: one loop does a lot

If you need the sum of many different stretches of a list, add things up once in advance. After that, the sum of any stretch is a single subtraction.

The idea

Think of your contactless or Oyster card history, which shows your total spent so far after each journey. How much did journeys 4 to 7 cost? You don't add up those four fares. You take "total after journey 7" minus "total after journey 3". Done.

A prefix sum list stores exactly that: the running total up to each position. You met it already in the toolkit lesson as Running Sum.

The trick that avoids special cases is to start the list with a 0 ("total before anything"). Then prefix[i] is the sum of the first i numbers:

Now the sum of nums[left] up to and including nums[right] is:

prefix[right + 1] - prefix[left]

Example with nums = [3, 1, 4, 1, 5]: the sum of indexes 1 to 3 is 1 + 4 + 1 = 6, and the formula gives prefix[4] - prefix[1] = 9 - 3 = 6. ✓

In Python

prefix = [0]
for x in nums:
    prefix.append(prefix[-1] + x)   # previous total + this number
# prefix has len(nums) + 1 items

def range_sum(left, right):         # inclusive on both ends
    return prefix[right + 1] - prefix[left]

Building the list is one pass: O(n) time and O(n) space. Every range sum after that is O(1). Without it, each range sum would loop over the range: O(n) each time.

Left side and right side

Some problems ask about "everything to the left of i" and "everything to the right of i". You don't even need the whole prefix list, just the total and a running left sum:

total = sum(nums)
left_sum = 0
for i, x in enumerate(nums):
    right_sum = total - left_sum - x   # everything after i
    # ...compare left_sum and right_sum here...
    left_sum += x                      # now includes nums[i]

LeetCode303. Range Sum Query - Immutable
Easy ~10 min☐ solved · https://leetcode.com/problems/range-sum-query-immutable/
Hint
This one is a small class. Build the prefix list in __init__ and store it as self.prefix. Then sumRange is the one-line formula.
Solution
class NumArray:
    def __init__(self, nums: List[int]):
        self.prefix = [0]
        for x in nums:
            self.prefix.append(self.prefix[-1] + x)

    def sumRange(self, left: int, right: int) -> int:
        return self.prefix[right + 1] - self.prefix[left]
LeetCode1413. Minimum Value to Get Positive Step by Step Sum
Easy ~10 min☐ solved · https://leetcode.com/problems/minimum-value-to-get-positive-step-by-step-sum/
Hint
Track the running total and its lowest point. If the lowest point is, say, -4, the start value must lift it to at least 1, so you need 5. The answer is never below 1.
Solution
class Solution:
    def minStartValue(self, nums: List[int]) -> int:
        total = 0
        lowest = 0                 # lowest running total seen
        for x in nums:
            total += x
            lowest = min(lowest, total)
        return 1 - lowest          # lifts the lowest point up to exactly 1
LeetCode2574. Left and Right Sum Differences
Easy ~10 min☐ solved · https://leetcode.com/problems/left-and-right-sum-differences/
Hint
Use the "left side and right side" template. Neither side includes nums[i] itself. Remember abs().
Solution
class Solution:
    def leftRightDifference(self, nums: List[int]) -> List[int]:
        total = sum(nums)
        left_sum = 0
        answer = []
        for x in nums:
            right_sum = total - left_sum - x
            answer.append(abs(left_sum - right_sum))
            left_sum += x
        return answer
LeetCode724. Find Pivot Index
Easy ~10 min☐ solved · https://leetcode.com/problems/find-pivot-index/
Hint
Same template again. Return the first index where left_sum == right_sum, or -1 if there isn't one.
Solution
class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left_sum = 0
        for i, x in enumerate(nums):
            if left_sum == total - left_sum - x:
                return i
            left_sum += x
        return -1
Interesting fact: Prefix sums found faces in photos

The same trick works in 2D. Store, for every pixel, the sum of all pixels above and to the left of it (a "summed-area table" or integral image). Then the brightness of any rectangle in the photo takes just four lookups, however big the rectangle.

In 2001, Paul Viola and Michael Jones used this to build the first face detector fast enough to run live on video. It checks thousands of rectangles per frame. Their method was used for years in digital cameras and is still built into OpenCV.

Remember

  • Build prefix with a leading 0: prefix[i+1] = prefix[i] + nums[i].
  • Sum of nums[left..right] = prefix[right+1] - prefix[left], in O(1).
  • "Left of i vs right of i": keep left_sum, and right = total - left_sum - nums[i].
