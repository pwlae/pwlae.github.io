Counting things

Read first: Hash maps and sets

Lots of problems become easy once you know how many times each thing appears. Build that tally first, then answer the question from the tally.

The idea

Picture a teacher counting votes on the board: one tick next to a name for every vote. When counting is done, questions like "who won?", "did anyone get exactly one vote?" or "did two people tie?" are answered just by looking at the board.

In code, the board is a dict from item to count, often called a frequency map.

In Python

By hand, with the .get(key, 0) trick from the toolkit lesson:

count = {}
for ch in "banana":
    count[ch] = count.get(ch, 0) + 1
# {'b': 1, 'a': 3, 'n': 2}

Python has a ready-made tool for this, Counter. It is a dict with extras:

from collections import Counter

count = Counter("banana")   # Counter({'a': 3, 'n': 2, 'b': 1})
count["a"]                  # 3
count["z"]                  # 0, missing keys count as 0 (no error)
count.most_common(1)        # [('a', 3)], the top item
Counter("listen") == Counter("silent")   # True: same letters, same counts

Building the tally is one pass: O(n) time, and O(k) space where k is the number of different items. On LeetCode, Counter is already imported for you.

Two passes: count, then look

The usual shape is two loops one after the other (not one inside the other, so still O(n)):

  1. Pass 1: build the counts.
  2. Pass 2: go through the input (or the counts) again and answer the question.

For example, "first letter that appears only once": pass 1 counts every letter, pass 2 walks the word in order and returns the first letter whose count is 1.

Shortcut for letters only

If the input is only lowercase letters a to z, you can use a list of 26 zeros instead of a dict. The letter's position is ord(ch) - ord("a") (from the Strings lesson):

count = [0] * 26
for ch in "banana":
    count[ord(ch) - ord("a")] += 1
# count[0] is "a": 3,  count[1] is "b": 1,  count[13] is "n": 2

LeetCode387. First Unique Character in a String
Easy ~10 min☐ solved · https://leetcode.com/problems/first-unique-character-in-a-string/
Hint
Two passes. Count all letters first. Then walk the string with enumerate and return the first index whose letter has count 1.
Solution
class Solution:
    def firstUniqChar(self, s: str) -> int:
        count = Counter(s)                 # pass 1: tally
        for i, ch in enumerate(s):         # pass 2: in original order
            if count[ch] == 1:
                return i
        return -1
LeetCode169. Majority Element
Easy ~10 min☐ solved · https://leetcode.com/problems/majority-element/
Hint
Count everything, then return the number whose count is bigger than len(nums) // 2. most_common(1) does it in one call.
Solution
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        return Counter(nums).most_common(1)[0][0]
# O(n) time, O(n) space.
#
# Bonus, O(1) space (Boyer-Moore voting): keep one candidate and a score.
# Same number as the candidate: +1. Different: -1. Score hits 0: pick a new
# candidate. The majority has more votes than everyone else combined, so it
# is the one left standing.
#     candidate, score = None, 0
#     for x in nums:
#         if score == 0:
#             candidate = x
#         score += 1 if x == candidate else -1
#     return candidate
LeetCode1207. Unique Number of Occurrences
Easy ~10 min☐ solved · https://leetcode.com/problems/unique-number-of-occurrences/
Hint
Count first. Then look only at the counts (count.values()): are they all different? Putting them in a set removes repeats.
Solution
class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        counts = list(Counter(arr).values())   # e.g. [3, 2, 1]
        return len(counts) == len(set(counts))  # no count repeated?
Interesting fact: Counting billions of visitors in 12 KB

To count exactly how many different people visited a website, you'd have to remember every visitor: gigabytes for a big site. Often "about 2.3 million, give or take 1%" is good enough.

HyperLogLog gives that kind of estimate using a tiny fixed amount of memory. Redis, a popular in-memory database, has it built in (PFADD / PFCOUNT): each counter uses at most 12 KB, whether it has seen a thousand items or billions, with an error of about 0.81%. Analytics tools use the same idea to count unique users.

Remember

  • Tally first: Counter(items) or count[x] = count.get(x, 0) + 1. O(n).
  • Then answer from the tally, often in a second pass over the input to keep the original order.
  • Letters only? A list of 26 counts with ord(ch) - ord("a") also works.
