A string is a row of characters, so almost everything you learned about lists works on strings too. This lesson adds the few string-only rules and tools you need for LeetCode.

The idea

Think of a string as a row of letter tiles, like in Scrabble. Each tile has an index, starting from 0, just like a list.

s = "hello"
s[0]        # "h"
s[-1]       # "o"
len(s)      # 5
s[1:4]      # "ell"
s[::-1]     # "olleh", reversed
for ch in s:
    print(ch)   # h, e, l, l, o

There is one big difference from lists: you can't change a string. s[0] = "H" is an error. Strings are immutable ("unchangeable"). Every "change" actually builds a brand-new string.

Build a list, then join

Because every change makes a new string, gluing letters on one at a time with += can copy the whole string again and again. The safe habit: collect the pieces in a list, then glue them once with "".join(...).

With s += ch, every step makes a new copy:

flowchart TD
  A1["h"] --> A2["he"] --> A3["hel"] --> A4["hell"] --> A5["hello"]

With a list and join, you collect the pieces and copy once at the end:

flowchart LR
  B1["['h', 'e', 'l', 'l', 'o']"] -->|"''.join()"| B2["hello"]

pieces = []
for ch in "hello":
    pieces.append(ch.upper())
result = "".join(pieces)    # "HELLO"

For short strings either way is fine. For long ones, the list-then-join way is reliably O(n).

Handy string tools

"a,b,c".split(",")       # ["a", "b", "c"]
"  hi  ".strip()          # "hi" (removes spaces at both ends)
"Hello".lower()           # "hello"
"a.b".replace(".", "!")   # "a!b"
"abc".isalpha()           # True: only letters?
"123".isdigit()           # True: only digits?
"-".join(["a", "b"])      # "a-b"

Characters are numbers underneath

Every character has a number code. ord turns a character into its number, and chr turns it back. Letters are in order, so you can do maths with them:

ord("a")        # 97
ord("b")        # 98
chr(97)         # "a"
ord("A")        # 65, capitals come 32 before lowercase

ord("c") - ord("a")   # 2: "c" is letter number 2 (counting from 0)

Your turn

Easiest first. For the first two, try both the built-in way and a "by hand" loop.

s.lower() is one line. By hand: for each character, if it is between "A" and "Z", add 32 to its ord and turn it back with chr. 
class Solution:
    def toLowerCase(self, s: str) -> str:
        pieces = []
        for ch in s:
            if "A" <= ch <= "Z":
                ch = chr(ord(ch) + 32)   # "A" (65) -> "a" (97)
            pieces.append(ch)
        return "".join(pieces)
# One line also works: return s.lower()
Replace every "." with "[.]". There's a method for that. 
class Solution:
    def defangIPaddr(self, address: str) -> str:
        return address.replace(".", "[.]")
# By hand: loop, append "[.]" for a dot, else the character, then join.
Watch out for spaces at the end, like "fly me to the moon ". split() with no argument splits on any run of spaces and drops empty pieces. 
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        return len(s.split()[-1])
# Without split: walk from the end, skip spaces,
# then count letters until the next space. O(n), O(1) space.
Look at the first word, one position i at a time. Check that every other word has the same character at i. Stop at the first mismatch, or when a word is too short. 
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        first = strs[0]
        for i in range(len(first)):
            for word in strs[1:]:
                # word too short, or a different letter here: stop
                if i == len(word) or word[i] != first[i]:
                    return first[:i]
        return first   # the whole first word is shared

Computers store text as numbers, and for years every country used different numbering systems that clashed. In September 1992, Ken Thompson and Rob Pike designed UTF-8 over dinner in a New Jersey diner, sketching it on a placemat. It stores plain English letters in 1 byte and other characters in 2–4 bytes.

Today almost every web page uses UTF-8. It's why len("é") in Python is 1 (one character) while len("é".encode()) is 2 (two bytes).
  • Strings work like lists (index, slice, loop, [::-1]) but can't be changed.
  • Build long strings as a list of pieces, then "".join(pieces).
  • ord/chr turn characters into numbers and back: ord(c) - ord("a") is the letter's position.
