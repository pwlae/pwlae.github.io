Before any algorithm, you need a few Python tools you will use in almost every problem: lists, loops, dictionaries and sets. This lesson is the toolbox.

What a LeetCode answer looks like

LeetCode gives you a class with one method. You fill in the method and return the answer. You never read input or print output yourself.

class Solution:
    def getConcatenation(
        self, nums: List[int]
    ) -> List[int]:
        return nums + nums

nums: List[int] is only a label: "nums is a list of whole numbers". -> List[int] says what you return. Python does not check these labels. They are there to help you read.

Lists: a row of boxes

A list is a row of boxes. Each box has a number called its index, starting from 0. In the picture, the index is on top and the value below it.

nums = [7, 2, 9, 4]
nums[0]    # 7, the first box
nums[-1]   # 4, the last box
len(nums)  # 4 boxes
# from index 1 up to (not including) 3
nums[1:3]  # [2, 9]
# add a box at the end
nums.append(5)  # [7, 2, 9, 4, 5]

Loops: visit every box

Most easy problems are "walk through the list once and keep track of something".

# just the values
for x in nums:
    print(x)

# just the indexes 0, 1, 2, ...
for i in range(len(nums)):
    print(i, nums[i])

# both at once (usually the nicest)
for i, x in enumerate(nums):
    print(i, x)

Handy built-ins

# add everything up
sum(nums)
# biggest, smallest
max(nums), min(nums)
# a new sorted list; nums is unchanged
sorted(nums)
# a new list built from nums
# (a "list comprehension")
[x * 2 for x in nums]

Dictionaries: labelled boxes

A dictionary (dict) stores key → value pairs, like a phone book. Looking up a key is instant. You do not search through everything.

age = {"ann": 31, "bob": 25}
age["ann"]       # 31
age["cat"] = 40  # add or change
"bob" in age     # True
# 0 if "dan" is missing (no error)
age.get("dan", 0)

count = {}
for w in ["a", "b", "a"]:
    count[w] = count.get(w, 0) + 1
# count is {"a": 2, "b": 1}

Sets: "have I seen this?"

A set keeps each value once, and checking "is it in there?" is instant.

seen = set()
seen.add(3)
3 in seen            # True
# duplicates are dropped
len(set([1, 1, 2]))  # 2

Your turn

These problems only need lists and loops. Aim for 5–10 minutes each.

Adding two lists with + puts them one after the other. 
class Solution:
    def getConcatenation(
        self, nums: List[int]
    ) -> List[int]:
        return nums + nums
Keep a running total. For each number, add it to the total and append the total to a new list. 
class Solution:
    def runningSum(
        self, nums: List[int]
    ) -> List[int]:
        result = []
        total = 0
        for x in nums:
            total += x
            result.append(total)
        return result
The x's are at indexes 0..n-1. The y's are at n..2n-1. So the pair number i is nums[i] and nums[i + n]. 
class Solution:
    def shuffle(
        self, nums: List[int], n: int
    ) -> List[int]:
        result = []
        for i in range(n):
            # x_i, then y_i
            result.append(nums[i])
            result.append(nums[i + n])
        return result
Each row is one customer. sum(row) is their wealth. You want the biggest one. 
class Solution:
    def maximumWealth(
        self, accounts: List[List[int]]
    ) -> int:
        best = 0
        for row in accounts:
            best = max(best, sum(row))
        return best
The list is small, so two loops are fine: for every i, check every j after it. Bonus: a dict of counts makes it one loop. 
class Solution:
    def numIdenticalPairs(
        self, nums: List[int]
    ) -> int:
        pairs = 0
        count = {}
        for x in nums:
            before = count.get(x, 0)
            # x makes a good pair with
            # each equal number seen
            # before it
            pairs += before
            count[x] = before + 1
        return pairs

A Python list asks for a bit more memory than it needs, about 12% extra. Most append calls then just fill a spare box. Only now and then does the list move to a bigger block of memory. Java's ArrayList, C++'s std::vector and Go's slices use the same trick, so adding to the end is cheap on average in all of them.
  • Lists start at index 0. nums[-1] is the last item.
  • for i, x in enumerate(nums) gives index and value together.
  • dict for "key → value", set for "have I seen it?". Both look things up instantly.
