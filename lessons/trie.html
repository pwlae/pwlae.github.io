A trie (say "try") is a tree that stores words letter by letter, so words that start the same way share the same path. It answers "is this word stored?" and "does any word start with this?" in a few steps, however many words you have.

The idea

Think of your phone's keyboard. You type "ca" and it suggests "car", "card", "care", "cat". It doesn't check every word in the dictionary. It follows c, then a, and everything below that point starts with "ca".

A trie is built exactly like that:

  • The root is an empty starting node.
  • Each step down is one letter. A node's children are the letters that can come next.
  • Words with the same start share nodes. "car", "card" and "care" all share c → a → r.
  • A node is marked end when a whole word stops there. That's how you know "car" is a word but "ca" is not.

A prefix is the start of a word: "ca" is a prefix of "card". Here is the trie for car, card, care and cat:

%%{init: {"flowchart": {"rankSpacing": 30, "nodeSpacing": 30}}}%%
flowchart TD
  R(("root")) --> C["c"]
  C --> A["a"]
  A --> RR["r ✓"]
  A --> T["t ✓"]
  RR --> D["d ✓"]
  RR --> E["e ✓"]

✓ means "a word ends here". To look up a word, start at the root and follow one letter at a time. If a letter is missing, the word isn't there.

In Python

Each node holds a dict of letter → child node, plus an end flag. The dict makes "is there a child for this letter?" instant.

class Node:
    def __init__(self):
        # letter -> child Node
        self.children = {}
        # does a word stop here?
        self.end = False

class Trie:
    def __init__(self):
        self.root = Node()

    def insert(self, word):
        node = self.root
        for ch in word:
            # no child yet? make one
            if ch not in node.children:
                node.children[ch] = Node()
            node = node.children[ch]
        # mark the last letter
        node.end = True

    def walk(self, text):
        # follow text letter by letter;
        # None if we fall off the trie
        node = self.root
        for ch in text:
            if ch not in node.children:
                return None
            node = node.children[ch]
        return node

    def search(self, word):
        node = self.walk(word)
        return node is not None and node.end

    def startsWith(self, prefix):
        return self.walk(prefix) is not None

All three operations take one step per letter: O(L) for a word of length L. It doesn't matter if the trie holds ten words or a million. Space is at most one node per letter inserted, less when words share a start.

A trie is a tree, so the depth-first ideas still work: to list every word below a node, walk down each child in turn.

Split the sentence into words. Python strings have word.startswith(x). Remember the answer counts words from 1, not 0. 
class Solution:
    def isPrefixOfWord(self, sentence: str, searchWord: str) -> int:
        words = sentence.split()
        # start=1: words are counted from 1
        for i, word in enumerate(words, start=1):
            if word.startswith(searchWord):
                return i
        return -1
The quick way is startswith. For trie practice: give every node a count of how many words pass through it. Then walk pref and read the count. 
class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:
        # quick way:
        # return sum(1 for w in words
        #            if w.startswith(pref))

        # trie way: each node counts
        # the words that pass through it
        new = lambda: {"count": 0, "kids": {}}
        root = new()
        for w in words:
            node = root
            for ch in w:
                if ch not in node["kids"]:
                    node["kids"][ch] = new()
                node = node["kids"][ch]
                # one more word passes here
                node["count"] += 1
        node = root
        for ch in pref:
            if ch not in node["kids"]:
                return 0  # no word starts so
            node = node["kids"][ch]
        return node["count"]

Stretch. Insert every word. A word can be "built" only if every node on its path is the end of a word. Go depth-first from the root, stepping only into children that are ends. Visit children in alphabetical order, and only replace your best answer with a strictly longer word. 
class Node:
    def __init__(self):
        self.children = {}
        # the word ending here, if any
        self.word = None

class Solution:
    def longestWord(self, words: List[str]) -> str:
        root = Node()
        for w in words:
            node = root
            for ch in w:
                if ch not in node.children:
                    node.children[ch] = Node()
                node = node.children[ch]
            node.word = w

        best = ""
        def dfs(node):
            nonlocal best
            # alphabetical order: on a tie,
            # the first word found is smallest
            for ch in sorted(node.children):
                child = node.children[ch]
                if child.word is None:
                    continue  # a gap: stop
                if len(child.word) > len(best):
                    best = child.word
                dfs(child)

        dfs(root)
        return best

Every packet sent across the internet carries a destination IP address. Each router must pick which way to send it, using a table of address prefixes, like "addresses starting with 192.168. go this way". When several prefixes match, the router uses the longest one, because it is the most specific. This is called longest prefix match.

Walking a trie bit by bit through the address finds that longest match naturally. The Linux kernel stores its IPv4 routing table in a compressed trie called an LC-trie ("level-compressed"), known in the source code as fib_trie.
  • A trie stores words letter by letter. Shared starts share nodes. An end flag marks where a word stops.
  • Each node is a dict of letter → child. insert, search and startsWith all walk one letter at a time: O(length of the word).
  • search needs end to be True. startsWith only needs the path to exist.
